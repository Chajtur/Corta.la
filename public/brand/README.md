# Identidad visual de corta.la

## Archivos

- `cortala-isotipo.svg`: símbolo cuadrado para avatar, app icon y espacios compactos.
- `cortala-isotipo-blanco.svg`: símbolo blanco sin fondo para colocarlo sobre fondos oscuros.
- `cortala-isotipo-monocromo.svg`: símbolo de un solo color; hereda `currentColor` al incrustarlo en HTML.
- `cortala-logotipo.svg`: nombre y descriptor sin símbolo.
- `cortala-imagotipo-horizontal.svg`: símbolo y nombre en composición horizontal.
- `cortala-imagotipo-vertical.svg`: símbolo y nombre en composición centrada vertical.
- `cortala-isologo.svg`: composición integrada dentro de una placa azul oscura.

## Idea

El símbolo transforma una URL larga (línea superior) en una más corta (línea inferior). La flecha indica la reducción y el punto celeste representa el inicio de la dirección.

## Colores

- Azul principal: `#2563EB`
- Azul degradado: `#3B82F6` a `#1D4ED8`
- Cian de acento: `#22D3EE`
- Azul tinta: `#10233F`
- Gris azulado: `#65758D`

## Uso

Usa el isotipo solo cuando el nombre de Corta.la ya esté visible o el espacio sea reducido. Usa el imagotipo horizontal en cabeceras y el vertical en piezas centradas. Reserva el isologo para fondos de marca y piezas promocionales. Mantén el espacio libre alrededor del símbolo y no alteres las proporciones ni los colores.

Los SVG son editables y escalables. El sitio usa el imagotipo horizontal y el isotipo como favicon.
